## 🎨 DYTR Studio (Interactive Educational & Continual Learning Platform)

DYTR Studio is a full-stack interactive companion studio built on top of the **dytr** core library, featuring:
- **10-Stage Pipeline**: Problem framing, data ingestion, architecture configuration, training arena, telemetry observatory, evaluation, and deployment.
- **Continual Learning Mechanics**: Interactive Elastic Weight Consolidation (EWC) shield and Experience Replay simulation.
- **FastAPI + PyTorch Engine**: Live bidirectional training bridge and standalone export capabilities.
